# 改写输出协议

v2.5 的正式入口是 [runner.py](runner.py)。它将本次 `instructions`、中性用户请求和原文放入一次冻结调用，不让改写模型读取判据、答案或历史评分。

输出只使用 `shuorenhua-rewrite-v1`：

```json
{"cases":[{"id":"B-01","text":"完整的实际交付内容"}]}
```

`text` 是用户实际会收到的稿件，包括请求需要的批注或删除建议。不改时仍返回完整原文；全文没有剩余正文时可简短说明，不能用空字符串。不要输出判定链、自评分或替代稿占位符。

每题 ID 必须与本批一致，不缺题、不重复、不加入新 ID。解析器不猜正文位置，不删除括号内容，不因其他题声明 no-op 就将本题当成原文保留。

实际提示拼装逻辑在 [runner.py](runner.py) 的 `build_prompt`，本文件说明合同，不是另一套改写规则。旧 Markdown 输出和固定判定链只用于复查历史运行。
