# v2.7.1 验证记录

**v2.7.1 修补了 `revision.md` 的三处细节和 `editing-guide.md` 的一处说明，并重写了 README 与五个安装页。** 针对这四处规则改动做了 12 次真实命令行定向测试（2026-11-18）：6 份修订稿清单定位 134/134、清单外实质差异 0、不再出现空行段号错标；两篇繁体新闻的总条数均比 v2.7.0 减少，但两个模型都仍有少量越界校对残留；默认模式 3 道短题未见误删承诺或误留空预告，不过两边处理 `B-33` 时都只读了 `SKILL.md`，没读 `editing-guide.md`，不能证明新增的那句说明起了作用。

这不是全量验收：没有跑模型主审，也没有重跑其余 8 篇修订稿长文、三种撤销和默认主集 123 条。全量过关数字仍以 [v2.7.0](results-v2.7.0.md) 和 [v2.6.0](results-v2.6.0.md) 为准。

## 改了什么

- `references/revision.md`：
  - `删除` 条目为唯一定位多带了保留字时，`改为` 允许直接写删后剩下的文字；整串全删仍写 `（删除）`。
  - `校对` 写明港台书面语、方言习惯用法不算语病；修语病若涉及补主语、选词义或改程度，原样留下，不标 `校对`。
  - 去掉强制按空行硬数 `### 第 N 段` 的要求，有小标题可按小标题分组，没有就直接顺排。
- `references/editing-guide.md`：看着 `B-33` 补了一句说明——对话中答应替对方处理某事，即使对象靠代词承接上文、后面紧跟重复的预告，前面的应承仍保留，不按空预告整段删空。
- `SKILL.md`、`references/examples.md` 和 `dist/shuorenhua-mini.md` 正文未改。

- **带保留字的删除**：先用新解析规则离线回放了 v2.7.0 Codex 在 `NORMAL-WN-3` 唯一挂掉的那第 8 条（`2024年初，刘帅被確診` → `刘帅被確診`），条目正常接纳，实质差异从 1 归 0。本次真实运行中，Claude Code 在 `NORMAL-WN-3` 第 2 条实际用上了这一写法（`降臨。2024年初，刘帅被確診` → `降臨。刘帅被確診`），正常定位并应用。6 份合计 134 条全部定位，清单外实质差异和小差异均为 0（Claude 的 `NORMAL-WN-3` 和 Codex 的 `NORMAL-WN-1` 结尾提示写了繁体「回覆」，计分正则未收「覆」字，正文无额外批注）。
- **段号**：6 份输出都不再写 `### 第 N 段`，直接按序号顺排，此前在那篇长文上错掉大半的段号问题不再出现。
- **`校对` 的改善与残留**：
  - 两篇繁体新闻的总条数均比 v2.7.0 下降（Claude 从 14、11 条降到 5、7 条；Codex 从 30、24 条降到 12、11 条，且不再把 `NORMAL-WN-1` 误判成「黑话较多」）。v2.7.0 待判的港式书面语 `有嘗試改變→有人嘗試` 和 `走近死亡一步→差點喪命` 本次两边都没有动。
  - **残留问题**：Claude Code 在 `NORMAL-WN-3` 仍把 v2.7.0 待判的 `首家富商施正榮` 标 `校对` 改成 `首富施正榮`，并把 `託了位瓦工為師` 改成 `拜了位瓦工為師`；Codex 在 `NORMAL-WN-1` 仍保留了 `她家只給祖父母的壓歲錢→她家只給祖父母壓歲錢`（删「的」选了一种读法）和一处报道来源移位，并在 `NORMAL-WN-3` 把粤语新闻惯用的 `大哥記得指`（「指」即表示）删成 `大哥記得`、把 `已過60歲花甲之年` 删成 `已過60歲`。两个模型在 `校对` 上的越界改句都有所减少，但都没清零。
